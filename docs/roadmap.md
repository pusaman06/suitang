## 1. 最后是什么样

### 1.1 在浏览器里（v1.0，第一周结束）

打开任意有字幕的 B 站视频：

1. **预习**：30 秒内，悬浮球旁出现「已预习」，点开能看到 8–15 段的大纲——这视频分几块、每块讲什么、从几分几秒开始。
2. **随时问**：暂停，或按 `Alt+Q`，面板弹出。问「这段在讲什么」「为什么这里要加锁」，5 秒内开始逐字回答，不是转圈等一整段。
3. **跳着看**：回答里的 `[12:30]` 是可点的，点一下视频跳到那儿，保持暂停，不会突然响。
4. **画面题**：问「这页 PPT 写的什么」，它会截当前帧一起看。
5. **接着问**：同一视频里可以连续追问，不用重复背景；刷新页面历史还在。
6. **没字幕也不崩**：明确告诉你「无字幕 · 只能按标题回答」，不会假装看过。

### 1.2 在 DSH 里（v1.1，第二周结束）

- 每个看过的视频，本地有一份 JSON（字幕 + 大纲 + 问答历史）和一份 Markdown（可直接读的讲稿）。
- 在 DSH 里说「上次那个讲 RAG 的视频说了什么」，技能能搜到、能按大纲总结、能顺着时间戳深挖。
- 标记「没懂」的时间点进复习清单。

### 1.3 明确不做（v1）

不做 ASR、不做 RAG / 向量库、不做华为云学堂等其它平台、不下载视频、不上架 Chrome 商店、不做移动端。

## 3. 每一步做什么

按每周 6–8 小时估算，D1–D8 约两周。每步格式：目标 → 交付 → 怎么算做完。

### D1 脚手架 ✅

- **目标**：能加载一个什么功能都没有的扩展，确认 MV3、构建、注入都通。
- **交付**：Vite 8 + TS 7 双入口（content / background）、悬浮球、多 P 识别、设置页骨架、MAIN world 取 cid。
- **验收**：用户截图确认悬浮球、P1/185 识别、后台连接正常。

### D2 字幕 ✅

- **目标**：拿到当前视频的完整字幕，并保证不是别的视频的。
- **交付**：`x/player/v2` 抓取（带登录态）、AI / 人工轨道按 aid/cid 校验、`sub:bvid:p:cid` 缓存、面板显示前 10 条。
- **验收**：`pnpm e2e` 断言面板出现「346 条」且正文含「零基础学AI」，storage 里有对应 key。

### D3 问答 🔶

- **目标**：问一个问题，5 秒内出字，答案带可点时间戳。
- **切片 1（已完成）**：常驻 port 流式问答、prompt 组装、SSE 解析、引用解析与跳转、无字幕兜底、mock 服务 + e2e。
- **切片 2（待做）**：多轮历史、`qaStore` 持久化、刷新恢复、usage 展示。
- **切片 3（待做）**：abort / 停止按钮、断线重连、切 P 自动取消。
- **验收**：`pnpm e2e` 11 条全绿 + 真实 Key 跑通（2026-11-05：首字 1.0s、`[00:06]` 点击后跳到 6s，截图 `e2e/screenshots/d3-real.png`）。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-qa.spec.ts`（没有 Key 时自动跳过）。

### D4 画面 ✅

- **目标**：问「这页写的什么」时，AI 能看到当前画面。
- **交付**：`captureVisibleTab` 截图 → 按视频可见区域裁剪 → 长边压到 ≤1280（`detail: high`）；截图时隐藏面板、悬浮球和 B 站弹幕层；截不到图降级纯文本；设置页可关「附带当前画面」。
- **验收**：`pnpm e2e` 17 条绿；真实 Key 暂停在 12s 问「这页写的什么」，2.7s 答出「ChatGPT (2022.11.30)」并带 `[00:12]`，截图 `e2e/screenshots/d4-real.png`。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-frame.spec.ts`（没有 Key 时自动跳过）。
- **还欠**：`frameError` 降级路径（全屏 / 权限拒绝 / 黑图）没有 e2e；可见面积 <50% 的提示文案没进 e2e。

### D5 大纲

- **目标**：打开视频就知道它分几块。
- **交付**：一次文本调用生成 8–15 段 `{start, end, title}`、缓存、预习卡 UI。
- **验收**：打开视频 30 秒内显示大纲，分段覆盖完整时长、不重叠。

### D6 落盘 + companion

- **目标**：视频数据不只在浏览器里。
- **交付**：本地 Node 服务 `127.0.0.1:8787`、每个视频一份 JSON + 一份 Markdown 写到 `D:\project\video-tutor\data\`、扩展侧同步队列（失败不阻塞问答）。
- **验收**：目录里出现 json / md；关掉 companion 扩展仍能问答。

### D7 DSH 技能

- **目标**：在 DSH 里复习看过的视频。
- **交付**：`video-notes` 技能（搜视频、读大纲、按时间戳追问）、文件格式说明。
- **验收**：DSH 里问「上次那个讲 RAG 的视频说了什么」能给出带时间戳的回答。

### D8 打磨

- **目标**：能交给别人用。
- **交付**：设置页完善（Key / 模型 / 预算）、错误态文案、图标、README、验收清单。
- **验收**：plan.md §11 验收清单全过。

## 4. 关键约束（别忘）

- **不碰视频流**：只拿字幕和暂停帧，规避下载和版权问题。
- **数据格式先定死**：D6 之前的存储结构按最终格式写，避免接 DSH 时返工。
- **扩展独立可用**：companion 挂了不影响实时问答。
- **BYOK**：Key 存 `chrome.storage.local`，只在 background 发请求时用，不进日志。
- **每一步都要能自己验证**：能自动化就 e2e，不能就截图；口头「做好了」不算。

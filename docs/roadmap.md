## 1. 最后是什么样

### 1.1 在浏览器里（v1.0，第一周结束）

打开任意有字幕的 B 站视频：

1. **预习**：30 秒内，悬浮球旁出现「已预习」，点开能看到 8–15 段的大纲——这视频分几块、每块讲什么、从几分几秒开始。
2. **随时问**：暂停，或按 `Alt+Q`，面板弹出。问「这段在讲什么」「为什么这里要加锁」，5 秒内开始逐字回答，不是转圈等一整段。
3. **跳着看**：回答里的 `[12:30]` 是可点的，点一下视频跳到那儿，保持暂停，不会突然响。
4. **画面题**：问「这页 PPT 写的什么」，它会截当前帧一起看。
5. **接着问**：同一视频里可以连续追问，不用重复背景；刷新页面历史还在。
6. **没字幕也不崩**：明确告诉你「无字幕 · 只能按标题回答」，不会假装看过。

### 1.2 在 DSH 里（v1.1，第二周结束）

- 每个看过的视频，本地有一份 JSON（字幕 + 大纲 + 问答历史）和一份 Markdown（可直接读的讲稿）。
- 在 DSH 里说「上次那个讲 RAG 的视频说了什么」，技能能搜到、能按大纲总结、能顺着时间戳深挖。
- 标记「没懂」的时间点进复习清单。

### 1.3 明确不做（v1）

不做 RAG / 向量库、不做华为云学堂等其它平台、不下载视频、不上架 Chrome 商店、不做移动端。ASR 见 D9（整段路径已做，长音频切片待补）。

## 3. 每一步做什么

按每周 6–8 小时估算，D1–D8 约两周。每步格式：目标 → 交付 → 怎么算做完。

### D1 脚手架 ✅

- **目标**：能加载一个什么功能都没有的扩展，确认 MV3、构建、注入都通。
- **交付**：Vite 8 + TS 7 双入口（content / background）、悬浮球、多 P 识别、设置页骨架、MAIN world 取 cid。
- **验收**：用户截图确认悬浮球、P1/185 识别、后台连接正常。

### D2 字幕 ✅

- **目标**：拿到当前视频的完整字幕，并保证不是别的视频的。
- **交付**：`x/player/v2` 抓取（带登录态）、AI / 人工轨道按 aid/cid 校验、`sub:bvid:p:cid` 缓存、面板显示前 10 条。
- **验收**：`pnpm e2e` 断言面板出现「346 条」且正文含「零基础学AI」，storage 里有对应 key。

### D3 问答 ✅

- **目标**：问一个问题，5 秒内出字，答案带可点时间戳。
- **切片 1（已完成）**：常驻 port 流式问答、prompt 组装、SSE 解析、引用解析与跳转、无字幕兜底、mock 服务 + e2e。
- **切片 2（已完成 2026-11-05）**：`qa:<bvid>:<p>` 落 `chrome.storage.local`（上限 100 条、schema 1）；刷新 / service worker 重启后历史还在，追问从存储读最近 `historyTurns` 轮；面板有「清空记录」，点两次确认；坏记录在读取时被过滤，不炸面板。
- **切片 3（待做）**：abort / 停止按钮、断线重连、切 P 自动取消。
- **验收**：`pnpm e2e` 32 条全绿（4 条真实 Key 用例无 Key 时跳过）+ 真实 Key 跑通（2026-11-05：首字 1.0s、`[00:06]` 点击后跳到 6s，截图 `e2e/screenshots/d3-real.png`、`e2e/screenshots/d3-history.png`）。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-qa.spec.ts`（没有 Key 时自动跳过）。

### D4 画面 ✅

- **目标**：问「这页写的什么」时，AI 能看到当前画面。
- **交付**：`captureVisibleTab` 截图 → 按视频可见区域裁剪 → 长边压到 ≤1280（`detail: high`）；截图时隐藏面板、悬浮球和 B 站弹幕层；截不到图降级纯文本；设置页可关「附带当前画面」。
- **验收**：`pnpm e2e` 17 条绿；真实 Key 暂停在 12s 问「这页写的什么」，2.7s 答出「ChatGPT (2022.11.30)」并带 `[00:12]`，截图 `e2e/screenshots/d4-real.png`。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-frame.spec.ts`（没有 Key 时自动跳过）。
- **还欠**：`frameError` 降级路径（全屏 / 权限拒绝 / 黑图）没有 e2e；可见面积 <50% 的提示文案没进 e2e。

### D5 大纲 ✅

- **目标**：打开视频就知道它分几块。
- **交付**：点「生成大纲」一次文本调用，按时长自适应 3–15 段 `{start, end, title}`，缓存到 `outline:<bvid>:<p>:<cid>`，面板内折叠区，点段跳转保持暂停。三级兜底：字幕 → UP 章节（`view_points`，不调模型）→ 抽帧（6/8/10 帧，`detail: low`，视觉模型 `frames-vision`；模型只给标题，时间戳由帧时间算）。
- **验收**：`pnpm e2e` 38 条绿；真实 Key 在 P1（891s）生成 9 段、4.6s，0–891s 首尾相接（`d5-real.png`）；`BV1XnxP6vEdX`（55s、无字幕无章节）抽 6 帧生成 5–6 段、6.5–8s（`d5-frames-real.png`）。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-outline.spec.ts e2e/real-frames.spec.ts`（没有 Key 时自动跳过）。
- **踩过的坑**：真实模型把 `start/end` 写成 `"10:32"` 字符串，`Number()` 得到 NaN，整份大纲被判坏格式（`e967cf4` 修：`toSeconds()` 兼容 mm:ss，prompt 也要求整数秒）；42 分钟视频被切成 27 段，超上限整份判坏（`60b56e5` 修：`coalesceSegments` 均匀合并）。
- **还欠**：抽帧会 seek，画面会跳几秒；6/8 帧档位没有单测；抓帧中途切 P 的中止路径没有 e2e。

- **未做**：图标、README、成本预算（没有 token 计量）。

### D9 ASR 语音转写（A 路径完成）

- **目标**：没有字幕、没有 UP 章节的视频，也能按语音提问和大纲。
- **交付**：硅基流动 `FunAudioLLM/SenseVoiceSmall`（当前免费）；面板在大纲区给「转写这段（约 N 分钟）」，点了才跑；background 读 `__playinfo__` 拿音轨、DNR 补 `Referer` 下载、整段上传；返回文本去 emoji / 压填充词 / 按标点切句，再按句在 `[0, duration]` 内均分造时间戳；缓存 `asr:<bvid>:<p>:<cid>`；大纲与问答都优先用它。
- **验收（2026-11-05，`BV14FHP6LEJE` 480 秒）**：转写 **7.1s**（175 句）、大纲 **2.1s**（10 段）、问答带 `[00:30]`/`[00:46]` 引用；合计约 12 秒。截图 `d8-asr-real.png`、`d8-asr-qa.png`。
- **已知限制**：SiliconFlow 只回整段文本、没有逐句时间，时间戳按句子数量均分，**引用跳转可能偏几十秒**；单次上限 1 小时 / 50MB。
- **未做（B 路径）**：FFmpeg.wasm 切片——超过约 55 分钟或 45MB 的音频目前会提示太长。

### D10 成本可见 ✅

- **目标**：知道每问一句花了多少钱，别让账单变成黑箱。
- **交付**：`src/shared/cost.ts`（deepseek-flash 峰谷定价、`isPeakHour`、`estimateCostUsd`、`USD_TO_CNY = 7.2`、`formatCny`）；`src/shared/usage-store.ts` 账本 `usage:ledger`（日 / 月 / 累计，跨天跨月自动重置）；回答行尾加 `· ≈¥0.0016`；面板同步行下加「今日 ¥x · 本月 ¥y」；设置页「用量」小节（本月 / 累计 / 月度预算进度 / DeepSeek 余额）。
- **计费口径**：只算 DeepSeek 的输入（缓存命中 / 未命中分开计价）和输出；`reasoning_tokens` 已含在输出里不重复计；转写用硅基流动，免费不计。
- **验收（2026-11-05 真实 Key）**：1336 tokens → 账本 `dayUsd 0.00021885` → 面板 `≈¥0.0016`，与手算一致；设置页拉到真实余额 `CNY 19.47`。截图 `d10-cost-real.png`。
- **限制**：按 $1=¥7.2 估算，不是实时汇率；中国法定节假日没从 peak 里扣（只按周末和时段判断）；历史回答只显示 tokens，不带费用（只有新回答带）。

## 4. 关键约束（别忘）

- **不碰视频流**：只拿字幕和暂停帧，规避下载和版权问题。
- **数据格式先定死**：D6 之前的存储结构按最终格式写，避免接 DSH 时返工。
- **扩展独立可用**：companion 挂了不影响实时问答。
- **BYOK**：Key 存 `chrome.storage.local`，只在 background 发请求时用，不进日志。
- **每一步都要能自己验证**：能自动化就 e2e，不能就截图；口头「做好了」不算。

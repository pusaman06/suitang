# 随堂 Suitang · 路线图

> 最后更新：2026-11-07
>
> **一句话**：在 B 站看课时，暂停就能问 AI；它读过整份字幕、能看当前画面，回答带可点的时间戳；生成的大纲和字幕可以一键存进本地知识库（`D:\knowledge-base`），在 DSH 里随时复习。
>
> 这份文档回答三个问题：**最终做成什么样、现在到哪一步、每一步怎么算做完**。
> 技术细节（接口、prompt、成本模型、风险）见 [plan-v0.1.md](./archive/plan-v0.1.md)（已归档的历史设计），这里不重复。

## 1. 最后是什么样

### 1.1 在浏览器里（v1.0）

打开任意 B 站视频：

1. **预习（点一下）**：大纲区点「生成大纲」。有字幕就用字幕切段（一般十几秒出十几段）；没字幕就先语音转写补字幕再切段；连人声都没有的纯音乐视频可以「按画面生成」，抽 6–10 帧看画面凑一份粗大纲。
2. **随时问**：暂停，或按 `Alt+Q`，面板弹出。问「这段在讲什么」，5 秒内开始逐字回答，不是转圈等一整段。
3. **跳着看**：回答里的 `[12:30]` 是可点的，点一下视频跳到那儿，保持暂停，不会突然响。
4. **画面题**：问「这页 PPT 写的什么」，它会截当前帧一起看。
5. **接着问**：同一视频里可以连续追问，不用重复背景；刷新页面历史还在。
6. **没字幕也不崩**：明确告诉你缺什么、下一步该点哪，不会假装看过；连人声都没有的纯画面视频，会提示你改用「按画面生成」。

### 1.2 已停 / 已恢复（原 v1.1）

- **已停（2026-11-07 收口）**：本地落盘（写 `data/videos` 的快照同步）已删；DSH 技能 `suitang` 目录保留，但它依赖落盘数据，暂不可用。
- **已恢复（2026-11-07 傍晚）**：知识库写入——面板「存到知识库」→ 本地 companion → 写进 `D:\knowledge-base`（`20-知识笔记` 索引卡 + `50-底稿` 字幕全文）。

### 1.3 当前版本不做

当前版本不做：RAG / 向量库、华为云学堂等其它平台适配、下载视频、上架 Chrome 商店、移动端。ASR 已在 D9 完成（超过 1 小时的音频暂不支持）。其中「其它平台」「商店上架」属于后续版本可能考虑的方向（见 §5），但不承诺。

## 3. 每一步做什么

按每周 6–8 小时估算，D1–D8 约两周。每步格式：目标 → 交付 → 怎么算做完。

### D1 脚手架 ✅

- **目标**：能加载一个什么功能都没有的扩展，确认 MV3、构建、注入都通。
- **交付**：Vite 8 + TS 7 双入口（content / background）、悬浮球、多 P 识别、设置页骨架、MAIN world 取 cid。
- **验收**：用户截图确认悬浮球、P1/185 识别、后台连接正常。

### D2 字幕 ✅

- **目标**：拿到当前视频的完整字幕，并保证不是别的视频的。
- **交付**：`x/player/v2` 抓取（带登录态）、AI / 人工轨道按 aid/cid 校验、`sub:bvid:p:cid` 缓存、面板显示前 10 条。
- **验收（2026-11-05）**：当时 e2e 断言面板出现「346 条」且正文含「零基础学AI」，storage 里有对应 key。（现在 e2e 用 mock 字幕，真实视频走 `e2e/real-*.spec.ts`。）

### D3 问答 ✅

- **目标**：问一个问题，5 秒内出字，答案带可点时间戳。
- **切片 1（已完成）**：常驻 port 流式问答、prompt 组装、SSE 解析、引用解析与跳转、无字幕兜底、mock 服务 + e2e。
- **切片 2（已完成 2026-11-05）**：`qa:<bvid>:<p>` 落 `chrome.storage.local`（上限 100 条、schema 1）；刷新 / service worker 重启后历史还在，追问从存储读最近 `historyTurns` 轮；面板有「清空记录」，点两次确认；坏记录在读取时被过滤，不炸面板。
- **切片 3（部分待做）**：切 P / 换视频已有「新请求顶掉旧请求」的 superseded 中止；停止按钮、断线重连未做。
- **验收（2026-11-05）**：当时 e2e 全绿（4 条真实 Key 用例无 Key 时跳过）+ 真实 Key 跑通（2026-11-05：首字 1.0s、`[00:06]` 点击后跳到 6s，截图 `e2e/screenshots/d3-real.png`、`e2e/screenshots/d3-history.png`）。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-qa.spec.ts`（没有 Key 时自动跳过）。

### D4 画面 ✅

- **目标**：问「这页写的什么」时，AI 能看到当前画面。
- **交付**：`captureVisibleTab` 截图 → 按视频可见区域裁剪 → 长边压到 ≤1280（`detail: high`）；截图时隐藏面板、悬浮球和 B 站弹幕层；截不到图降级纯文本；设置页可关「附带当前画面」。
- **验收（2026-11-05）**：当时 e2e 全绿；真实 Key 暂停在 12s 问「这页写的什么」，2.7s 答出「ChatGPT (2022.11.30)」并带 `[00:12]`，截图 `e2e/screenshots/d4-real.png`。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-frame.spec.ts`（没有 Key 时自动跳过）。
- **还欠**：`frameError` 降级路径（全屏 / 权限拒绝 / 黑图）没有 e2e；可见面积 <50% 的提示文案没进 e2e。

### D5 大纲 ✅

- **目标**：打开视频就知道它分几块。
- **交付**：点「生成大纲」一次文本调用，按时长自适应 3–15 段 `{start, end, title}`，缓存到 `outline:<bvid>:<p>:<cid>`，面板内折叠区，点段跳转保持暂停。两种方式：**按字幕**（模型按行号切段，时间戳由字幕行反查；少字幕时允许一行一段、按可用行数放宽段数下限）→ **按画面**（没字幕时抽 6–10 帧，模型只给标题，时间戳由帧时间算）。
- **验收（2026-11-05）**：当时 e2e 全绿；真实 Key 在 P1（891s）生成 9 段、4.6s，0–891s 首尾相接（`d5-real.png`）；`BV1XnxP6vEdX`（55s、无字幕无章节）抽 6 帧生成 5–6 段、6.5–8s（`d5-frames-real.png`）。
- **怎么复跑**：`$env:DS_KEY='sk-...'; pnpm exec playwright test e2e/real-outline.spec.ts e2e/real-frames.spec.ts`（没有 Key 时自动跳过）。
- **踩过的坑**：真实模型把 `start/end` 写成 `"10:32"` 字符串，`Number()` 得到 NaN，整份大纲被判坏格式（`e967cf4` 修：`toSeconds()` 兼容 mm:ss，prompt 也要求整数秒）；42 分钟视频被切成 27 段，超上限整份判坏（`60b56e5` 修：`coalesceSegments` 均匀合并）。
- **还欠**：抽帧会 seek，画面会跳几秒；6/8 帧档位没有单测；抓帧中途切 P 的中止路径没有 e2e。

### D8 打磨 ✅

- **目标**：能交给别人用。
- **交付**：设置页补齐「跳转后自动播放 / 回答长度上限 / 追问轮数」；错误文案补 `finish_reason`（内容过滤、算力紧张）；图标、README（含「数据外发」与免责声明）、成本预算（见 D10）；设置页 Key 不回填、API 地址只走 https（本机回环例外）。

### D9 ASR 语音转写 ✅

- **目标**：没有字幕的视频，也能按语音提问和大纲。
- **交付**：硅基流动 `FunAudioLLM/SenseVoiceSmall`（当前免费）。无字幕时 ≤15 分钟的视频自动转写，更长的点「转写这段」手动跑；background 读 `__playinfo__` / 页面缓存拿音轨，按候选顺序（标准 CDN 优先、P2P 最后、最低码率）逐个尝试，DNR 补 `Referer` 下载后整段上传，超时 300 秒；多 P 按 URL 的 `?p=` 定位当前 cid；返回文本去 emoji / 压填充词，再按标点打包成 ≤80 字符的字幕行，按行在 `[0, duration]` 内均分造时间戳；缓存 `asr:<bvid>:<p>:<cid>`；大纲与问答都优先用它。
- **验收（2026-11-05，`BV14FHP6LEJE` 480 秒）**：转写 **7.1s**（175 句）、大纲 **2.1s**（10 段）、问答带 `[00:30]`/`[00:46]` 引用；合计约 12 秒。截图 `d8-asr-real.png`、`d8-asr-qa.png`。长视频 `BV1aRxX6iE7h`（52 分钟）走最低码率音轨转写成功，大纲 12 段。
- **已知限制**：SiliconFlow 只回整段文本、没有逐句时间，时间戳按句子数量均分，**引用跳转可能偏几十秒**；单次上限 1 小时 / 50MB，超过的音频提示太长（不做 FFmpeg 切片）。转写文本信息量过低（<50 字或 <0.8 字/秒）时不出大纲，提示改用「按画面生成」。

### D10 成本可见 ✅

- **目标**：知道每问一句花了多少钱，别让账单变成黑箱。
- **交付**：`src/shared/cost.ts`（deepseek-flash 峰谷定价、`isPeakHour`、`estimateCostCny`、`formatCny`）；`src/shared/usage-store.ts` 账本 `usage:ledger`（日 / 月 / 累计，跨天跨月自动重置）；回答行尾加 `· ≈¥0.0014`；面板同步行下加「今日 ¥x · 本月 ¥y」；设置页「用量」小节（本月 / 累计 / 月度预算进度 / DeepSeek 余额）。
- **计费口径**：**直接用官网中文定价页的人民币单价（元 / 百万 tokens）**，不做汇率换算——缓存命中空闲 0.02 / 高峰 0.04，未命中空闲 1 / 高峰 2，输出空闲 4 / 高峰 8。只算输入（命中 / 未命中分开）和输出；`reasoning_tokens` 已含在输出里不重复计；转写用硅基流动，免费不计。
- **验收（2026-11-05 真实 Key）**：1324 tokens → 面板 `≈¥0.0014`（手算 500×0.02 + 634×1 + 190×4 = 0.001404 元，吻合）；设置页拉到真实余额 `CNY 19.47`。截图 `d10-cost-real.png`。
- **限制**：中国法定节假日没从 peak 里扣（只按周末和时段判断）；历史回答只显示 tokens，不带费用（只有新回答带）；账本 schema 升到 2（字段从 `*Usd` 改为 `*Cny`），旧账本作废。

## 4. 关键约束（别忘）

- **不碰视频流**：只拿字幕和暂停帧；语音转写时音轨只在内存里中转上传、不落盘，规避下载和版权问题。
- **唯一落盘出口是知识库**：写 `D:\knowledge-base`（D11），浏览器内缓存只做本地加速，不算数据资产。
- **扩展独立可用**：companion 挂了只影响「存到知识库」，字幕、大纲、问答照常。
- **BYOK**：Key 存 `chrome.storage.local`，只在 background 发请求时用，不进日志；设置页不回填明文。
- **每一步都要能自己验证**：能自动化就 e2e，不能就截图或 probe 脚本；口头「做好了」不算。
